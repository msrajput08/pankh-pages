# PankhPages — Free Printable Worksheets

Live website: https://pankhpages.netlify.app/

PankhPages is a static worksheet-generator website featuring Marathi, Hindi, English, tracing and maths worksheets. `dist/` contains the deployable Netlify site. This repository is being populated from the existing deployment; original build sources are archived separately.
